Frontend: vite,react, axios 

vite: Szybki i dobrze zoptymalizowy dev server 

react: Łatwa budowa UI bazująca na komponentach, duży ekosystem 

axios: prosta implementacja api, pozwala na łatwe wyświetlenie np. progressu wczytania pliku 



Backend: Node.js, Express, cors, dotenv, multer, gemini 

Express: lekki framework do obsługi api 

cors: Do obługi Cross-Origin Resource Sharing, tak aby możliwość komunikacji z backendem była wyłącznie przez serwer frontendu 

dotenv: Do wczytania api_key z pliku .env 

multer: dla prostszego przetważania plików i walidacji pdf

gemini: użyłem gemini-2.5-pro ponieważ może on przetwarzać pliki
