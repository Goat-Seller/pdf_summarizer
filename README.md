Frontend: vite,react, axios\n

vite: Szybki i dobrze zoptymalizowy dev server\n
react: Łatwa budowa UI bazująca na komponentach, duży ekosystem\n
axios: prosta implementacja api, pozwala na łatwe wyświetlenie np. progressu wczytania pliku\n\n

Backend: Node.js, Express, cors, dotenv, multer, gemini\n
Express: lekki framework do obsługi api\n
cors: Do obługi Cross-Origin Resource Sharing, tak aby możliwość komunikacji z backendem była wyłącznie przez serwer frontendu\n
dotenv: Do wczytania api_key z pliku .env\n
multer: dla prostszego przetważania plików i walidacji pdf\n
gemini: użyłem gemini-2.5-pro ponieważ może on przetwarzać pliki\n\n
